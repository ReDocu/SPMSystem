### 0.2 공통 레이아웃 — 사이드바 (확정: 상시 노출)

```
┌────────┬──────────────────────────────────────────┐
│ SPM    │                                          │
│        │                                          │
│ ◷ 일정  │            (기능 페이지 본문)               │
│ ▤ 프로젝트│                                         │
│ ⚙ 운영·배포│                                        │
│ ◈ 자료수집│                                         │
│ ──────  │                                         │
│ 📥 인박스 ⑦│                                        │
│ ⚙ 설정   │                                         │
│        │                                          │
│ ⌘K 입력 │                                          │
└────────┴──────────────────────────────────────────┘
```

- 메인 런처(`/`)에는 사이드바 없음 — 관문 역할만
- 인박스에 미처리 카운트 표시. 배지 규칙은 0.4 참조
- 하단 ⌘K 힌트 클릭 = 커맨드 팔레트 열기

### 0.3 커맨드 팔레트 (⌘K)

```
┌──────────────────────────────────────────┐
│ > 14-16 SPM 개발_                         │
│   ⏱ 오늘 타임로그로 저장  (14:00–16:00) ①  │
├──────────────────────────────────────────┤
│   ↵ 인박스에 저장                          │
│   → 이동: 일정 / 프로젝트 / 운영 / 자료      │
└──────────────────────────────────────────┘
```

| 요소 | 명세 |
|---|---|
| ① 추정 미리보기 | 자동 추정 규칙(URL→자료, 날짜→할 일, `#프로젝트`→태스크, 시간 범위→타임로그, 그 외→아이디어)의 결과와 파싱 값을 입력 아래 인라인 표시 |
| 저장 | Enter 한 번. 추정이 틀려도 인박스에서 재분류 가능하므로 확인 단계 없음 |
| 이동 | 텍스트가 없을 때는 페이지 이동 커맨드 목록 |

### 0.4 공통 규칙

- **배지**: 🔴 지금 조치(다운·오늘 마감 미완료) / 🟡 1주 내(만료 D-7) / 없음 = 정상. 평상시 대부분 꺼져 있어야 한다
- **삭제**: 즉시 실행 + 5초 되돌리기 토스트. 확인 모달 금지
- **처리 완료**: 0.3초 페이드 아웃
- **모달 최소화**: 생성·수정은 인라인 입력 우선. 예외는 게이트 카드(§5.6)뿐
- **다크모드** 지원, 지연 항목은 목록 안에서 빨간 텍스트로 직접 표시

## 4. 일정

상단 공통: `[◀] 2026-08-27 (목) [▶] [오늘]     [ 일별 | 달별 | 연별 ]` — 탭 전환 시 날짜 문맥 유지.

### 4-1. 일별 기록지 `/schedule/day/:date` — 매일 여는 기본 화면

```
┌───────────────────────────────┬────────────────────┐
│ ▸ 00–06 (접힘) ①               │ □ 오늘 할 일 ⑤       │
│ 06 ─                          │  ☐ 로그인 API  #SPM  │
│ 07 ─                          │  ☑ 병원 예약         │
│ 08 ─                          │ ▸ 못 한 일 (1) ⑥     │
│ 09 ─ ▓ SPM 개발 #SPM ──┐ ②    │ ▸ 백로그 (12) ⑦      │
│ 10 ─                  │      │                    │
│ 11 ─ ─────────────────┘      │ ◷ 오늘 일정 ⑧        │
│ 12 ─ 점심                     │  15:00 병원         │
│ ══ 13:42 현재 ══ ③            │  🎂 결혼기념일        │
│ 14 ─ (빈 슬롯 — 클릭해 입력) ④   │                    │
│ 15 ─                          │ ✎ 데일리 노트 ⑨      │
│ ...                           │ ☺ 컨디션 😀🙂😐🙁 ⑩   │
├───────────────────────────────┴────────────────────┤
│ 기록 9h · #SPM 5h · #블로그 2h · 기타 2h ⑪            │
└────────────────────────────────────────────────────┘
```

| 요소 | 명세 |
|---|---|
| ① 00–06 접힘 | 기본 접힘 + 펼침 버튼 |
| ② 타임로그 블록 | 1시간 스냅(저장은 분). 연속 동일 활동은 한 블록. `#프로젝트` → 연결 + 프로젝트 색. 경계 드래그로 시간 조절, 클릭으로 인라인 수정 |
| ③ 현재 시각 라인 | 오늘 열람 시 자동 스크롤 기준 |
| ④ 빈 슬롯 | 클릭 → 인라인 입력 → Enter. 드래그 → 범위 블록. 회색으로 조용히 — 채우라는 압박 금지 |
| ⑤ 오늘 할 일 | `planned_date = 오늘`. 체크 가능. 입력 텍스트가 태스크 제목과 일치하면 타임로그-태스크 연결 제안 (`actual_min` 누적) |
| ⑥ 못 한 일 (n) | `planned_date` 지난 미완료(누적). 재선정 or 백로그 반환, 7일 경과 시 자동 반환 |
| ⑦ 백로그 (접이식) | 마감·계획일·`target_year` 없는 미완료 태스크(프로젝트 배지 구분). 오늘로 드래그 = `planned_date` 지정. 연간 목표는 제외 |
| ⑧ 오늘 일정 | event 읽기 전용. 카테고리 아이콘(기념일🎂·수업·출장). 지난 일정엔 [기록으로 복사] 원탭 → 타임로그 변환 |
| ⑨ 데일리 노트 | 한 줄 크기의 입력. 긴 글 유도 안 함 |
| ⑩ 컨디션 | 이모지 1탭 (선택 등급 — 안 해도 무압박) |
| ⑪ 하루 요약 | 프로젝트별 집계 한 줄. 통계 화면은 v0.6 |
| 빈 화면 | 첫 방문에만 "빈 칸을 눌러 기록해보세요" 힌트 1회 |
| 모바일 | 타임라인만. 우측 패널은 상단 접이식 요약 |

### 4-2. 달별 현황판 `/schedule/month/:yyyy-mm`

```
┌────────────────────────────────────────┬──────────────┐
│  월  화  수  목  금  토  일               │ 8월 집계 ⑤     │
│ ┌────┬────┬────┬────┐                  │ #SPM   42h   │
│ │ 4  │ 5  │ 6  │ 7  │                  │ #블로그 12h    │
│ │▓▓░ │▓░░ │    │▓▓▓ │ ← 기록 띠 ①       │ 완료 태스크 18 │
│ │─수업─│    │🎂  │    │ ← 일정 바/배지 ②   │              │
│ │•마감 │    │    │◆MS │ ← 마감·마일스톤 ③  │ 남은 마감 ⑥   │
│ └────┴────┴────┴────┘                  │  8/29 API v1 │
│ ┌────┬────┬─  ...                      │  8/31 ◆MVP   │
│ │ 11 │ 12 │                            │              │
└────────────────────────────────────────┴──────────────┘
```

| 요소 | 명세 |
|---|---|
| ① 기록 띠 (주인공) | 그날 타임로그를 프로젝트 색 비율 띠로 압축. 읽기 전용. 한 달 = 시간 배분 히트맵 |
| ② 일정 레이어 | 카테고리 색 바/배지. **이 화면에서 CRUD** — 빈 셀 더블클릭 → 인라인 생성(제목/시간/카테고리), 드래그로 날짜 이동. 반복은 rrule, 회차 취소·변경은 시리즈/회차 선택 |
| ③ 마감·마일스톤·배포 | 표시만 (체크는 일별, 소유는 각 영역). 지난 마감 미완료 빨간 텍스트 |
| 날짜 클릭 | 해당 일별 기록지로 드릴다운 (기본 내비게이션) |
| ⑤ 월간 집계 | 프로젝트별 누적 시간·완료 태스크·진행률 변화 |
| ⑥ 남은 마감 | 이번 달 마감·마일스톤 목록 |
| 규칙 | 주 시작 월요일. 주간 뷰 없음. 여러 날 일정(출장)은 가로 바 표시만(리사이즈 후순위) |
| 빈 화면 | "이번 달 기록이 없습니다" → 오늘 기록지 유도 |

### 4-3. 연별 목표 `/schedule/year/:yyyy`

```
┌──────────────────────────────────────────────┐
│  [◀] 2026년 [▶]                    7/15 완료 ① │
│                                              │
│  ☑ SPM v0.1 실사용 시작            #SPM  ≡ ②  │
│  ☐ 블로그 30편 작성                      ≡    │
│  ☐ 이직 포트폴리오 정리                   ≡    │
│  ☒ ~~알고리즘 스터디~~  (dropped)         ≡    │
│  [+ 올해 하고 싶은 일]                         │
│                                              │
│  🎂 올해의 기념일 ③                            │
│   2월 결혼기념일 (지남)   9월 부모님 생신 D-12    │
│   [+ 기념일]                                  │
└──────────────────────────────────────────────┘
```

| 요소 | 명세 |
|---|---|
| ① 헤더 | `n/m 완료`만. 진행률 바 없음(압박 방지). 지난 연도는 읽기 전용 아카이브 |
| ② 항목 | task 상태 그대로(todo→doing→done↘dropped). done·dropped는 취소선으로 잔존. ≡ 드래그 수동 정렬, 그룹핑 없음. 마감일 부여 시 그대로 일반 태스크가 되어 달별·런처에 등장. 프로젝트 연결 시 개요 탭 노출 |
| ③ 기념일 패널 | 월별 그룹, D-day 표시, 지난 것 흐림. 여기서도 CRUD(달별과 동일 event) |
| 연말 이월 | 미완료 일괄 처리: "내년으로 보내기" or dropped |
| 빈 화면 | "올해 하고 싶은 일을 적어보세요" |

```
│  ▾ 대기중 (3)                                 │
│   │ ● 블로그 리뉴얼  [planning]        │       │
│   │ ● 미니게임      [idea]            │       │
│  ▸ 완료 (4)                                  │
│  ▸ 폐기 (2)   ← "회고 미작성" 배지 가능          │

```

| 요소 | 명세 |
|---|---|
| 그룹(확정: 4개) | 진행중(active·live) → 대기중(idea·planning·paused, 세부 배지) → 완료(접힘) → 폐기(접힘) |
| 카드 | 색 도트 + 제목 + 진행률 바 4px + 최근 활동일 + 이번 주 투입 시간(타임로그) |
| idea 그룹 | 아이디어 풀 역할 (별도 아이디어 인박스 없음) |
| 회고 미작성 배지 | 완료·폐기인데 회고 없으면 상시 표시 (조용함 원칙의 유일 예외) |
| 빈 화면 | "첫 프로젝트를 만들어보세요" |

## 9. 모바일 (PWA) 공통

- 홈 화면 아이콘, 공유 시트 → 인박스 캡처 직행
- **하단 고정 [+] FAB → 캡처 시트** — ⌘K의 모바일 대체 (ISSUE-03)
- 런처: 2×2 그리드 유지
- 일별: 타임라인 단독 + 상단 접이식 요약(할 일·일정). **입력은 드래그 대신 탭 → 시간 범위 시트** (ISSUE-02)
- 달별·연별·프로젝트·운영: 세로 스택으로 리플로우, 사이드 패널은 하단 이동
- 미구현 버전의 탭·메뉴는 숨김 — 빈 껍데기 노출 금지 (ISSUE-11)
